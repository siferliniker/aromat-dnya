# Аромат дня — статус проекта

Текущая задача — **Telegram Mini App, локальная версия готова к дальнейшей проверке в Telegram**. По запросу пользователя интерфейс перенесён с сообщений на карточки внутри приложения. Разработка ведётся в ветке `stage2-opinions`, опубликованный этап 1 закреплён коммитом `1191dc0`. Этап 2 со сбором обзоров ещё не принят.

### Решения и входные данные этапа 2

- Пользователь выбрал PARFUM4MEN и Masculinor. Для рассмотрения найдены Persolaise и The Perfume Guy. Список доверия и разрешение на получение/обработку контента проверяются отдельно.

- Метрика названий — micro-F1 по каноническим ID, с отдельным выводом precision/recall. Тональность считается по всем ожидаемым упоминаниям, пропуски и неверные названия ухудшают результат. Синтетические тесты не заменяют человеческую разметку.

- Для версий обзоров используется существующая `SourceRevision` без изменения ORM. Новая версия сохраняется и при пустом извлечении, чтобы старые упоминания не выдавались за текущие.

- Первые агенты QA, LLM и security-review были прерваны лимитом использования сервиса. Новые независимые проверки завершены, работа продолжена. Успешная генерация пока не подтверждена. [Биллинг OpenAI](https://platform.openai.com/settings/organization/billing)

[Условия captions.download](https://developers.google.com/youtube/data/reference/rest/v3/captions/download)
- Нет 30–50 разрешённых текстов с независимой человеческой разметкой для проверки порогов. Файл с выдуманными отзывами или модельной разметкой как принятый эталон не создавался.
- Пользователь делегировал выбор страны. Для планируемого API worker выбран целевой регион Германия из поддерживаемого списка, но фактический хост и условия доступа аккаунта ещё требуют подтверждения. Это проектное решение не меняет географию текущего локального компьютера. [Поддерживаемые страны](https://developers.openai.com/api/docs/supported-countries)
