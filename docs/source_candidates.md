# Кандидаты для обзоров

В `data/source_admissions.json` записаны выбранные пользователем [PARFUM4MEN](https://www.youtube.com/@PARFUM4MEN) и [Masculinor](https://www.youtube.com/@Masculinor). Начальные веса доверия равны 1.0. Права на получение, хранение, обработку и цитирование ещё не подтверждены. Источник имеет статус `pending`, выключен, все операции запрещены, список разрешённых материалов пуст.

Для последующего рассмотрения найдены иностранные авторы [Persolaise](https://persolaise.com/) и [The Perfume Guy](https://theperfumeguy.net/). Они пока остаются кандидатами. Проверенные идентификаторы каналов и разрешения для проекта не зафиксированы, в реестр допуска они не добавлены.

Telegram-каналы пользователь пока не указал. Записи для них в реестре нет. Условия допуска и ограничения источников описаны в [матрице](sources.md).
