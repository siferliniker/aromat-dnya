## Подключено сейчас

- Fragella:16 точных совпадений в текущих300 записях, включая Detour Noir и Guidance. Категории Longevity/Sillage переведены без выдуманных голосов или числовой точности.
- Scent Grail: Essenza, Intensa и Club de Nuit Woman; значения обозначены как опыт автора.
- Источник, дата получения и доступная уверенность сохраняются. Число голосов не возвращается API, поэтому остаётся неизвестным.
- Передача в API содержит только бренд/название и ключ доступа, без Telegram ID, истории и реакций. Ключ лежит в исключённом из Git `.env`.
- Кэш —отдельная таблица performance_cache в существующей зашифрованной базе; ограничение64 записи,24часа. Полные ответы первичных запросов остаются только в закрытой рабочей папке.local. Не включать их в публичный репозиторий.
- Для новых карточек используется только бесплатный план. API-запросы не выполняются при поисковой выдаче списком; подробности догружаются по нажатию.
- При несовпадении концентрации, неединственном совпадении или отсутствии полей метрика не подставляется.

Документация: https://api.fragella.com/docs.html ; условия: https://api.fragella.com/terms-of-use.html

## Будущий импорт распределений голосов

В карточке нужны стойкость, шлейф, сезон, время суток и распределение голосов.
Плановый формат импорта связывается с исходным `external_id`, а не с похожим названием:

```json
{
  "external_id": "publisher-perfume-id",
  "source_url": "https://example.com/perfume",
  "observed_at": "2026-11-11T00:00:00Z",
  "access_basis": "Лицензия или разрешённый экспорт",
  "longevity_votes": {"very_weak": 0, "weak": 0, "moderate": 0, "long_lasting": 0, "eternal": 0},
  "sillage_votes": {"intimate": 0, "moderate": 0, "strong": 0, "enormous": 0},
  "season_votes": {"spring": 0, "summer": 0, "autumn": 0, "winter": 0},
  "time_votes": {"day": 0, "night": 0}
}
```

Это спецификация следующего подключения, а не уже действующий импортёр.
Ноль голосов означает отсутствие голосов, а не слабую стойкость. Пропущенное
поле означает отсутствие сведений. Отдельно сохраняются размер выборки и дата;
производные шкалы не подменяют исходные голоса и не превращаются в точные часы.

Условия Fragrantica от 14 января 2026 запрещают автоматическое получение данных
без письменного разрешения, в том числе через внутренние API. Автоматический
адаптер не включён. Для продолжения нужен разрешённый API, лицензированная выгрузка
или иное подтверждённое основание; одного наличия публичной страницы недостаточно.
