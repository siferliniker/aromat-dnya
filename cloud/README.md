# Облачная Mini App

Worker сохраняет интерфейс из `miniapp/static`, каталог и API существующей Python-версии. D1 хранит состояние одного владельца с AES-256-GCM; Telegram `initData` проверяется сервером, срок действия — час. PNG нот находятся в R2. Для работы опубликованной версии локальный компьютер не нужен.

Исходники размещения живут в `cloud/`. Отдельный checkout Sites, сборки и временные файлы находятся внутри исключённого из Git `.local/sites/aromatia`. Его `.openai/hosting.json` содержит выданный Sites ID и логические bindings `d1: "DB"`, `r2: "BUCKET"`, без поля `static`.

Скопируйте `cloud/` и `miniapp/static/` в checkout с теми же относительными путями. Сборка без зависимостей: `node cloud/build.mjs`. Результат — `dist/server/index.js` и метаданные миграции D1. Публикация выполняется штатным workflow Sites с точным исходным commit и архивом сборки.

Секреты задаются через runtime environment Sites: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `WORKER_DATA_KEY` (отдельный случайный ключ, 64 hex), `BOOTSTRAP_STATE` (только для первой инициализации), `PERFORMANCE_SEED` (ранее полученные показатели), `FRAGELLA_API_KEY`. Значения не входят в исходники, архив или браузер. Локальная резервная копия ключа облачного шифрования хранится в защищённом `.env`.

При переносе сохраняются ID карточек, реакции, просмотренные ароматы, история прежних отправок и текущая карточка. Последняя операция отмены начинается заново. Bootstrap используется только при отсутствующей строке состояния; после проверки переноса удалите его секрет. Отсутствие bootstrap при пустой базе приводит к ошибке, а не созданию пустой коллекции.

При отсутствии PNG сервер берёт исходный файл из публичного GitHub-репозитория, закреплённого в `cloud/public-assets.json`, проверяет размер и SHA-256 и сохраняет в R2. Только два имени из сборки, без произвольных URL и перенаправлений. Ручная загрузка, административный upload endpoint и отдельный токен не нужны.

Fragella вызывается только для открытой карточки, после проверки бесплатного тарифа и остатка `/usage`. Каталог и коллекции используют кэш. Кэш шифруется, ограничен 64 записями; TTL — 24 часа для результата и 15 минут для отсутствия совпадения. Общая блокировка D1 защищает квоту от параллельных запросов. `FRAGELLA_ENABLED=false` отключает внешние вызовы при проверке переноса.

Публичная оболочка сайта нужна для открытия непосредственно из Telegram. Личный API и при таком размещении доступен только владельцу. По умолчанию Sites создаёт закрытый сайт; аудитория меняется отдельным действием после согласия владельца.

В `catalogue.json` только публичные карточки закреплённого набора Scento и ручные дополнения проекта. Данные [Scento](https://www.scento.com/perfume-database) — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), атрибуция и происхождение описаны в `data/scento/manifest.json`. Изменения: выборка 300 записей, нормализация полей, русские переводы и ручные дополнения. Изображения имеют собственные источники в карточках. Личные отметки и ответы API Fragella в этот файл не экспортируются. Снимок каталога можно получить скриптом `cloud/export_catalogue.py` внутри действующего контейнера.

Работа рассчитана на бесплатные лимиты Cloudflare; отсутствие расходов навсегда не гарантируется условиями провайдера Sites. Проект не подключает платный Workers-план и не разрешает платные поиски Fragella.
