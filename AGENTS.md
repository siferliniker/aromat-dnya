Создавай рабочие и временные папки, виртуальные окружения, кэши, логи, установщики и локальные данные этого проекта только внутри `D:\Ароматия`. Используй исключённый из Git каталог `D:\Ароматия\.local` для локальных артефактов и отдельную подпапку для временных файлов каждого запуска. Не создавай рабочие файлы и каталоги в корне `D:\`.
